# 드림닥터 지점 확장 랜딩페이지 — 배포 안내

## 폴더 구성

```
index.html              메인 랜딩페이지
privacy.html            개인정보처리방침
assets/                 이미지 9종 + OG 이미지
fonts/                  페이퍼로지 3종 (woff2)
functions/api/contact.js   문의 폼 수신 (Cloudflare Pages Functions)
_headers                캐시 · 보안 헤더
robots.txt / sitemap.xml   검색엔진용
```

전체 1.5MB. 첫 화면 로딩에 필요한 용량은 약 700KB입니다.

---

## 1. 올리기 전에 바꿀 것

**도메인 주소를 넣으세요.** 세 파일에 `REPLACE-YOUR-DOMAIN`이 들어 있습니다.
찾아 바꾸기로 실제 도메인(예: `partner.dreamdoctor.co.kr`)으로 교체하십시오.

| 파일 | 위치 |
|---|---|
| `index.html` | canonical, og:image, og:url |
| `robots.txt` | Sitemap 줄 |
| `sitemap.xml` | loc 줄 |

**개인정보처리방침을 검토하세요.** `privacy.html`의 보유 기간(상담 종료 후 1년),
보호책임자, 위탁 업체는 실제 운영 정책에 맞게 확인이 필요합니다.

---

## 2. Cloudflare Pages에 배포

1. Cloudflare 계정으로 로그인 → **Workers & Pages** → **Create** → **Pages**
2. **Upload assets** 선택 (깃허브 연동 없이 폴더째 업로드)
3. 이 폴더의 **내용물 전체**를 드래그합니다. 폴더 자체가 아니라 안의 파일들입니다.
4. 배포가 끝나면 `프로젝트명.pages.dev` 주소가 생깁니다. 여기서 먼저 확인하세요.
5. **Custom domains** 탭에서 도메인을 연결합니다. HTTPS 인증서는 자동 발급됩니다.

수정할 때는 같은 화면에서 새로 업로드하면 됩니다. 이전 버전으로 되돌리기도 지원됩니다.

## 3. 문의 폼 연결 — 반드시 하세요

폼은 `/api/contact`로 데이터를 보냅니다. 이 함수는 `functions/` 폴더에 들어 있어
Cloudflare Pages가 자동으로 인식합니다. 다만 **메일 발송을 위해 환경 변수 3개를
등록해야 합니다.**

1. [resend.com](https://resend.com) 가입 후 API 키를 발급받습니다. 무료 플랜으로 충분합니다.
2. Resend에서 발신 도메인을 인증합니다 (DNS 레코드 추가).
3. Cloudflare Pages → 프로젝트 → **Settings** → **Variables and Secrets**에 등록합니다.

| 이름 | 값 |
|---|---|
| `RESEND_API_KEY` | Resend에서 발급받은 키 |
| `MAIL_TO` | `sdj1011@hanmail.net` |
| `MAIL_FROM` | `no-reply@인증한도메인` |

4. 등록 후 **재배포**해야 적용됩니다.

### 등록하지 않으면

폼은 정상 접수되고 사용자에게 완료 메시지가 뜨지만 **메일이 오지 않습니다.**
문의 내용은 Cloudflare 로그에만 남습니다. 광고를 돌리기 전에 반드시 설정하고,
실제로 테스트 문의를 넣어 메일이 도착하는지 확인하세요.

### 다른 방법

Resend 대신 Formspree, Google Forms, 슬랙 웹훅 등을 쓰셔도 됩니다.
`functions/api/contact.js`의 발송 부분만 바꾸면 됩니다.

## 4. 광고 추적 붙이기

`index.html`의 `<head>` 안에 이런 주석이 있습니다.

```html
<!-- ▼ 광고 추적 스크립트를 여기에 붙여넣으세요 -->
```

구글 애즈, 메타 픽셀, 네이버 프리미엄 로그 분석 등의 스크립트를 여기에 넣으세요.

**전환 이벤트는 이미 연결되어 있습니다.** 폼 전송이 성공하면 아래가 자동 실행됩니다.

- `gtag('event','generate_lead')` — 구글 애널리틱스 · 애즈
- `fbq('track','Lead')` — 메타 픽셀
- `wcs_do()` — 네이버
- `lead_submitted` 커스텀 이벤트 — 그 외 도구용

해당 스크립트를 붙이면 별도 작업 없이 전환이 잡힙니다.

## 5. 배포 후 점검

- [ ] `.pages.dev` 주소에서 페이지가 정상적으로 열리는가
- [ ] 모바일에서 히어로 지표(18만 명+ 등)가 0으로 보이지 않는가
- [ ] 평수 슬라이더 계산기가 동작하는가 (주니어 30평 = 7,500만원)
- [ ] 전화번호를 눌렀을 때 전화 앱이 열리는가
- [ ] **테스트 문의를 보내고 메일이 실제로 도착하는가**
- [ ] 개인정보처리방침 링크가 열리는가
- [ ] 카카오톡에 주소를 붙여 미리보기 이미지가 뜨는가
- [ ] 광고 도구에서 전환 테스트가 잡히는가

## 참고 · 이번에 적용한 최적화

| 항목 | 내용 |
|---|---|
| 이미지 분리 | base64 내장 → 개별 파일. 브라우저 캐시가 동작합니다 |
| 폰트 분리 | 622KB 폰트를 별도 파일로. 재방문 시 다시 받지 않습니다 |
| 지연 로딩 | 첫 화면 밖 이미지 4장에 `loading="lazy"` 적용 |
| 우선 로딩 | 히어로 캐릭터에 `fetchpriority="high"` 적용 |
| 캐시 헤더 | 이미지·폰트 1년 캐시, HTML은 항상 최신 확인 |
| 스팸 방지 | 폼에 허니팟 필드 추가. 봇이 채우면 자동 무시 |
| 폼 검증 | 필수 항목과 동의 체크를 전송 전에 확인 |
| 실패 대비 | 전송 실패 시 전화번호와 메일 주소를 안내 |
